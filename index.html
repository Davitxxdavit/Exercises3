2. Paragraphs and Text Formatting

This is a regular paragraph. The paragraph tag (p) is used to define blocks of text. It automatically adds spacing before and after the content.

You can use bold text and strong text to emphasize content.

You can also use italic text and emphasized text for different styling.

Here are more formatting options:

  • Underlined text using the u tag
  • Highlighted text using the mark tag
  • Small text using the small tag
  • Deleted text using the del tag
  • Inserted text using the ins tag
  • This is subscript and this is superscript
  • Computer code using the code tag
  • Keyboard input using the kbd tag
  • Sample output using the samp tag
  • Variable using the var tag
